# Temperature Converter

This is my Java program for Lab 1, Project 2.

It asks for a Celsius temperature and converts it to Fahrenheit. Then it asks for a Fahrenheit temperature and converts it to Celsius. Both results show 2 decimal places.

To use it, run TemperatureConverter.java and enter the temperatures when asked.

The program uses Scanner for input, lambdas with the TempConverter interface for conversions, and printf for the results.
