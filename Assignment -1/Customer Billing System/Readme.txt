# Customer Billing System

This is my Java program for Lab 1, Project 1.

It asks how many TVs, VCRs, remote controllers, CD players, and tape recorders were sold. It calculates the item totals, adds 8.25% sales tax, and prints a receipt.

To use it, run CustomerBill.java and enter the quantity for each product.

The program uses Scanner for input, constants for prices, and printf to format the receipt.
