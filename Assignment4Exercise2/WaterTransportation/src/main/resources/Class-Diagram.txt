RELATIONSHIPS

CargoShip  --|> Ship
CruiseShip --|> Ship

ShipDriver creates Ship, CargoShip, and CruiseShip objects.
Its main method stores them in a local Ship[] array.

Calling print() through each Ship reference runs the actual
object's version of the method. This demonstrates polymorphism.
