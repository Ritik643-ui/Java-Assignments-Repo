## Topics Covered

- Variables, calculations, and formatted output
- User input with Scanner
- Loops and methods
- Classes, objects, constructors, getters, and setters
- Arrays and ArrayList
- Static fields and methods
- Inheritance and polymorphism
- Exception handling

## Running the Programs

Open the assignment project in IntelliJ IDEA or another Java IDE, then run its main or driver class. Some programs ask for input, while others use sample data in the driver.

Assignment folders contain Java source files and, where included, documentation, class diagrams, and test output.
